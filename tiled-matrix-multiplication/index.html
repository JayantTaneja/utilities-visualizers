How the Algorithm Works

Standard multiplication computes each output element as C[i][j] = sum(A[i][k] * B[k][j]). Tiled multiplication groups this work into square blocks (tiles) so data loaded from memory can be reused before fetching the next tile.

  1. Split matrices into tile-sized blocks along rows/columns.
  2. For an output tile C(tr, tc), iterate over k-tiles.
  3. Load one tile from A and one tile from B into shared memory.
  4. Multiply-accumulate to update partial sums in the output tile.
  5. Repeat for the next k-tile until the output tile is complete.

In GPU-style execution, many output tiles are processed in parallel. This visualizer simulates that by advancing all output tiles together per k-tile wave in Parallel mode.
